셀 **96×144**, 셀 내부 기준점 **(48,135)**, scale 3, Lanczos3, 투명 배경을 기존 규칙대로 유지했습니다. NPC는 0~6행의 0~3열만 사용하고, 오른쪽 4열과 마지막 행은 완전히 투명합니다. 행 순서는 **주간 점원 → 야간 점원 → 경비원 → 촬영 스태프 → 트레이너 → 사서 → 학예사**입니다. 기존 NPC와 같은 포즈 높이 120/105/111/111px입니다. 식빵은 황갈색·흰색, 선 귀·짧은 다리·긴 몸·식빵 엉덩이로 구분했고, 다리를 숨긴 낮잠을 마지막 칸에 넣었습니다. 회장님과 같은 바닥에서 무릎 주변 높이가 되도록 작게 배치했습니다.
