# 출석 도장판 아기자기 UI 반영 보고

## 바꾼 점
- **파일 범위 준수**: [hani-attendance-board.css](../../hani-attendance-board.css), [hani-attendance-board.js](../../hani-attendance-board.js) 두 파일만 수정했습니다. (`localStorage` 키 `hani_attendance_v1`, Cloud 로직, 당번 순서, 대사, `taeo`→`채원` 이름, `hani-attendance-core.js` 계산 로직 그대로 유지)
- **폰트 및 카드**: `hani-attendance-board.css` 최상단에 Google Fonts `Jua`·`Gowun Dodum` `@import`를 추가하고, 카드 모서리 `18px`·은은한 보라 그림자(`rgba(80, 50, 140, ...)`)를 적용했습니다.
- **당번 머리·말풍선**: 원형 프로필(`.face`, `50%`)과 `M월 D일(요일) · 오늘의 출석/동물 당번` 태그, 큰 둥근 글씨 이름(`Jua`), 왼쪽 위가 뾰족한 연보라 말풍선(`border-radius: 4px 14px 14px 14px`)으로 재배치했습니다.
- **7칸 도장·애니메이션**: 점선 원형 도장 칸(`.att-mark`) 아래에 `요일 일자`를 두고, 찍으면 분홍 도장 + `쾅!` 커졌다 작아지는 `att-pop` 애니메이션, 오늘 칸은 보라 실선, 쉬는 날은 초록 칸(`🍀`)으로 바꿨습니다.
- **보상 상자·연속 출석·버튼**: 금색 테두리 보상 상자(`.att-reward`, 7일 비밀 한마디 및 마일스톤 안내), 3일 이상 시 통통 튀는 `att-hop`, 14일 카드 금색 그라데이션(`.gold`), 30일 `👑 개근 후원자` 배지, 큰 분홍 연속 일수(`Jua`) + 둥근 알약 버튼(`오늘 도장 쾅!`)을 적용했습니다.
- **접근성·반응형**: 밝은 테마 4종과 어두운 테마(`data-theme="dark"`, `midnight-black`, `titanium-graphite`)에서 대비를 확보했고, `480px` 이하(390px 포함) 가로 넘침 방지 및 `prefers-reduced-motion: reduce` 시 애니메이션 비활성화를 유지했습니다.

## 11/14 시안과 같은 점 · 다른 점
- **같은 점**: `Jua`/`Gowun Dodum` 글꼴, 원형 프로필, 뾰족한 연보라 말풍선, 7칸 원형 점선→분홍 도장/보라 오늘/초록 휴식, `pop`/`hop` 모션, 금색 보상 상자, 분홍 연속 출석 숫자, 알약 버튼, `18px` 카드와 보라 그림자.
- **다른 점**:
  1. 시안의 하단 시험 단추/로그는 넣지 않았고, `HaniAttendance` 엔진(월~일 주간, 자동 휴식·컴백 알림, 저장소 불가 경고)을 그대로 연결했습니다.
  2. 동물 당번(치즈·크림·보리·모찌)은 시안의 base64 대신 기존 앱의 `./assets/sprites-v3/pet-*.webp` 스프라이트를 원형 프레임과 보상 상자 아이콘에 그대로 재사용합니다.
  3. 30일 `👑 개근 후원자` 배지와 `🐾 동물 당번 날` 배지는 상단 헤더 줄에 배치해 카드 레이아웃이 흔들리지 않도록 했고, `14일` 금색 카드 테두리는 앱 기존 기준(`v.unlocked.includes(14) || v.streak >= 14`)을 유지했습니다.
  4. 쉘 실행이 비활성화된 환경이므로 실제 브라우저 렌더링 및 JS 실행 검증은 수행하지 못했습니다(정적 코드 작성만 완료).
