## 코어·복도 실측

좌상단 (0,0), 원화 픽셀, 육안 경계 판독 약 ±5px. 문 중심과 바닥 문턱을 구분합니다. 논리 도식 1000×640 좌표가 아닙니다.

| 기준 | 기존 | 새 그림 |
| --- | --- | --- |
| 1F 엘리베이터 문 | bbox (297,56)~(434,262), 중심 (366,159), 문턱 (366,262) | bbox 약 (297,56)~(434,262), 중심 (366,159), 문턱 (366,262) |
| 1F 계단 | 좌상단 bbox (0,0)~(245,307), 하부 합류 (120,300) | 같은 위치, 합류 약 (120,300) |
| 1F 정문 유리문 | bbox 약 (610,627)~(1055,815), 중앙 바닥 (833,815) | 같은 위치·프레임, 중앙 바닥 약 (833,815) |
| 1F 카페 | 우측 키오스크 bbox 약 (1450,565)~(1671,790) | 같은 자리·카운터 외곽, 인물·메뉴 글자 제거 |

새 5F 문은 옥상 문과 x≈837로 맞췄습니다. 문 중심 y는 옥상보다 약 16px 낮고 문턱은 약 3px 낮습니다. 층별 코어 동일 좌표 요구는 최종 결정으로 대체했습니다. 2F·4F에는 보이는 승강기/계단이 없으며, 새 5F에도 별도 노출 계단은 없습니다. 5F 러너는 기존 2F/4F의 좁은 세로 통로 폭·시점을 따르되 무늬와 원근 경계까지 픽셀 동일하지는 않습니다. 층별 앵커 초안은 [anchor-candidates.json](anchor-candidates.json)에 별도 기록했습니다.

## 검수 결과와 남은 경계

- 필수 4구역과 소품 육안 확인: 5F 방송 데스크 2석·카메라·조명, 서가·공부 2석·소파·스크린, 러닝머신 **2대**·요가매트 **2장**, 키즈매트·책장·텐트·빈 펫 쿠션 **4개**. 1F 냉장 진열·계산대·온수바 2석, 안내·일보판·택배함·상담 2석, 출근 게이트, 기존 위치 카페.
- 최종 2장 전체와 코어 확대 육안 확인: 사람·동물·읽을 수 있는 글자·숫자·로고 0. 간판·메뉴·게시 종이는 비워 뒀습니다. 자동 OCR 판정은 수행하지 않았습니다.
- 낮 조명·시점·바닥·유리 칸막이·채색을 기존 층과 나란히 확인. [6장 비교판](side-by-side.png).
- 최종 WebP로 정확한 50% 블렌드 생성·직접 확인: [5F↔2F](overlay-5f.png), [5F↔4F](overlay-5f-4f.png), [1F↔기존 1F](overlay-1f.png). 1F 코어·정문·카페 정렬 확인; 5F 복도 정렬 보정 1회, 과다 러닝머신/엘리베이터 높이 보정 1회. [코어 확대](core-readback-final.png).
- 기존 층 4장 SHA-256 불변 확인. 규격·용량·포맷·해시 결과는 [validation.json](validation.json). 저장 경로·코드·버전·캐시·데이터·Cloud 변경 없음.
- 걸리는 점: 5F는 용량 우선 Q78. 가구 뒤 착석/바리스타 발 위치·전경 가림·48×64 캐릭터/이름표·실제 앱/모바일·라이트/다크 테마는 코드 연결 시 미검증 항목입니다. 아트 파일 제작 완료와 앱 적용·배포 완료를 구분합니다.
