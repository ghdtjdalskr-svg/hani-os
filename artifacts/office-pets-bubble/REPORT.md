# 반려동물 움직임·말풍선 닫기

2026-11-06 KST · Codex · `hani/office-pets-bubble` · base/확인한 원격 main `461dfdff` · 미커밋.

확인한 원인은 **닫힌 말풍선이 자동 대화로 곧바로 다시 열리는 것**입니다. 실제 주민 일정인 11월 6일 17:03:47에 세 동물 대화를 열고 배경을 누르면, 기존 코드에서는 다음 100ms 갱신이 같은 자동 대화를 다시 열었습니다. 수정 전 실패·수정 후 통과를 기록했습니다. 다만 대표님 PC의 동일 원인인지는 실제 브라우저 접근 차단으로 확정하지 못했습니다.

기존 document pointerdown 하나를 capture 단계로 바꾸고, 명시적 닫기는 예약 대사·오래된 타이머를 취소하며 같은 자동 동물 대화 구간을 소비합니다. 주민 자동 대화도 마지막 사용자 동작 뒤 5초간 기다립니다. 앱의 stopPropagation이 실제 원인이라는 증거는 확보하지 못했으며, capture는 하위 핸들러의 전파 차단에도 닫히도록 하는 보완입니다. 직원·동물·바리스타·목록 행의 기존 열기와 프로필 링크는 유지했습니다.

반려동물은 이동 주기가 치즈·크림 60~120초, 모찌 120~180초이고, 짧은 제스처도 10~20초마다 한 번뿐입니다. 정지 구간에서 기존 제스처의 마지막 프레임이 유지되어 오래 멈춰 보일 수 있었습니다. 기존 sprite에 상시 작은 몸 움직임을 추가했습니다. 발 위치를 고정하고 몸을 최대 가로 2%·세로 3% 안쪽으로 줄여 기존 예약 영역 밖으로 나오지 않습니다. 기존 산책·홉·회전·수면·애정 동작은 우선하며, 화면 밖과 감소 모션에서는 추가 애니메이션이 멈춥니다. 새 이동 경로나 타이머는 없습니다. 실제 움직임의 체감·겹침은 화면 검증이 남았습니다.
