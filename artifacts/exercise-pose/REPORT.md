**용량 FAIL:** 픽셀 완전 보존을 위해 정적 무손실 WebP(exact=True, method=6, quality=100)로 저장했다. 기존 4포즈만 같은 방식으로 저장해도 유리를 제외한 5명은 이미 100,000 bytes를 넘는다. 원래 품질 88 손실 저장 실험은 6장 모두 예산 안이지만 기존 픽셀 해시가 바뀐다. 두 조건을 함께 달성하지 못했으며, 예산 PASS나 최종 채택 완료로 보고하지 않는다. 상세 수치는 validation.json의 originalOnlyLosslessBytes와 lossyDiagnostic 참조. 손실 실험은 메모리에서만 수행했다.

**검증:** Python 3.14 / Pillow 13.0.0, pack.py와 finalize.py 실행. 24개 해시·새 포즈 구분·예약 행/열 알파 0·셀/atlas·보호 파일 84개 원문 보존 확인. 최종 WebP 재디코딩 비교판을 직접 시각 확인했다. 두 포즈의 발은 기존 발/바닥 위치에 맞췄다.

**불확실/미검증:** 생성 특성상 얼굴 세부·머리 볼륨·선 굵기·옷 음영의 완전 동일성은 보장하지 않는다. 수연/하루의 풍성한 머리와 기울임 프레임의 가장자리, 기존 서기와의 미세 크기 차이는 대표님 미술 검토가 필요하다. 유리는 양손 스트레칭을 위해 클립보드를 들지 않는다. 실제 renderer·반복 재생 타이밍·브라우저/Production은 미검증이다.

**불확실/미검증:** 최종 WebP를 재디코딩한15명 비교판을 전부 직접 확인했다. 생성 특성상 얼굴 세부·머리 볼륨·선 굵기·옷 음영·서기 대비 크기에는 미세 차이가 있다. 넓은 머리·기울임은 셀 안에 맞추면서 전체 크기가 약간 줄 수 있고, 일부 바닥 그림자 농도·미르 그림자·윤슬 치마 길이는 원본과 차이가 남는다. taeo 프로필 명찰은 ‘채원’, daon·yoonseul 프로필과 현재 서기 머리 모양은 다르므로 서기 셀을 우선했다. 소품은 내려놓았다. 실제 renderer·반복 재생·브라우저·Production은 미검증. 미술 채택·원본 적용·Git/커밋은 서윤 인계다.

Git·앱/runtime·assets·버전/cache·데이터·Cloud 변경 없음. Build/One-Pass/HINA는 아트 산출물 범위이므로 N/A. 이전 파일럿의 용량 FAIL 기록은 당시 무손실 결과의 이력이며, 이번 최종21장의 용량 결과는 위 표가 기준이다.
