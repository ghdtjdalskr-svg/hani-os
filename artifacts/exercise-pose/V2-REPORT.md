# v2 운동 프레임 반영

2026-11-29 KST · Codex · **19장·38프레임 반영 및 저장본 검증 완료**.

[6배 최근접 비교판](compare-v2.png) · [프레임별 상세 측정](v2-validation.json) · [재현·반영·검증 스크립트](v2_pack.py).

384×512 atlas·48×64 셀 유지. 첫 행 4열 `exercise`=[192,0,48,64], 5열 `exercise-b`=[240,0,48,64], pivot=[24,61]. v3 셀만 1/3 축소했으며 새 그림 생성·보정은 없다. `sourceRect`는 v3에서 복사하고 `contentRect`는 최종 WebP의 alpha>0 bbox를 셀 상대 [x,y,w,h]로 측정했다.

## 축소 재현 확인

기존 패커와 HD exporter 원문에서 **Sharp Lanczos3·기본 premultiplied alpha 보간·sharpen 없음·손실 WebP quality88/alphaQuality100/effort6**을 확인했다. 먼저 기존 v3 0~3열을 같은 설정으로 축소·패킹한 뒤 기존 v2와 비교했고, 이후 운동 두 셀에도 같은 축소 함수를 적용했다.

하니 서기 1셀 재현의 평균 절대 RGBA 차이는 **축소 직후 10.71956, 기존 네 셀을 함께 WebP 저장한 뒤 8.93685**였다(0~255, 투명 픽셀 RGB 포함). 흰 바닥에 합성한 RGB 평균 차이는 4.15997이다. **픽셀 완전 재현은 되지 않았다.** 기존 두 버전은 공통 원화를 각각 다른 해상도로 리샘플링·손실 압축했고, v3는 운동 추가 시 재압축도 거쳤다. 필터 설정은 원문 근거로 맞췄으며 수치가 가장 작은 필터를 임의로 선택하지 않았다. 모든 인물·기존 네 셀의 재현 오차와 여섯 필터 진단은 상세 JSON에 있다. 이 재현 이미지는 기존 v2 셀에 덮어쓰지 않았다.

다온·윤슬은 기존 v2 manifest가 구 원화 `<id>.webp`를 가리키며 v3와 `sourceSha256`도 다르다. 서기 재현 오차는 각각 20.86027·39.56803이다. 요청대로 기존 v2 파일·네 프레임·원화 메타데이터는 유지하고 v3 운동만 추가했다. 별도 `daon-v2.webp`·`yoonseul-v2.webp`는 변경하지 않았다. 따라서 두 인물의 기존 서기와 새 운동 간 외형 차이가 비교판에 보인다.

## 검증·인계

Sharp0.35.5/libvips8.18.7/WebP1.6.0으로 패킹한 실제 파일을 **Pillow13.0.0으로 별도 재디코딩**해 크기·해시·용량·76프레임 차이·알파·38 bbox/sourceRect/pivot·빈 예약 셀을 대조했다. 미대상 manifest6개 항목의 원문 바이트·키 순서·2칸 들여쓰기·LF·끝 개행 보존. v3·미대상 v2·기존 아트 산출물·JS/CSS/HTML 등 보호파일354개 SHA-256 보존. 실제 최종19명 비교판을 직접 시각 확인했다.

실행: Python3.14.7에서 `v2_pack.py --diagnose` → `--apply` → `--verify`(PASS). 원본 바이트는 `scratch/v2-baseline.json`에 보존했다. 검사는 이미지·manifest 전용 LIGHT 범위다. JS syntax·DOM/event·저장/Cloud 검사는 해당 변경이 없어 N/A. Full Build·One-Pass·HINA·실제 renderer/브라우저·Production은 미실행/미검증. 버전·cache·Git·배포 변경 없음. 커밋은 서윤 인계.

## v2b 다온·윤슬 실제 렌더링 파일 수정 (최종 상태)

2026-11-29 KST · 위 최초 결과 중 두 인물은 이 절로 정정한다. 렌더러의 `spriteSource`는 manifest의 프레임 좌표로 **`daon-v2.webp`·`yoonseul-v2.webp`**를 그린다. 두 파일의 384×512 atlas·48×64 셀·기존 0~3열/빈 4~7열을 먼저 확인하고, v3 운동 셀만 같은 **Sharp Lanczos3·기본 premultiplied alpha·sharpen 없음** 방식으로 축소해 `[192,0,48,64]`·`[240,0,48,64]`에 넣었다. [비교판](compare-v2.png)은 두 인물의 실제 -v2 서기와 새 두 셀을 나란히 표시하며 직접 시각 확인했다.

| 실제 파일 | bytes / 품질 | 기존 0·1·2·3열 평균 RGBA 절대차 |
|---|---:|---|
| daon-v2.webp | 9,664 / 88 | 1.35815 · 1.57918 · 1.39380 · 1.49162 |
| yoonseul-v2.webp | 11,104 / 90 | 1.66545 · 1.63721 · 1.69889 · 1.94865 |

윤슬 품질88·89는 기존 셀 하나가 2를 넘어 최초 통과 품질90을 사용했다. **8셀 모두 평균차 <2.0·알파 동일**, 압축 전 새 두 셀 밖 RGBA 동일. 구 `daon.webp`·`yoonseul.webp`는 Git 명령 없이 HEAD `0afacc260cdc29bffd3ee4d38179d119f081ef0e`의 객체를 읽고 SHA-1 검증하여 **원본 바이트 그대로 복원**했다(각7,428·8,408 bytes). 이전 보존 원본과도 정확히 일치하며 manifest의 `sizeBytes`·`sha256`·`alpha`는 HEAD 값으로 복원했다.

manifest에는 운동 두 프레임을 유지하고 **여섯 프레임의 `contentRect`를 실제 -v2 셀 alpha>0 bbox**로 맞췄다. **-v2 파일의 bytes/sha 전용 필드는 없으므로 추가하지 않았다.** `spriteBytes`는 현재 값265,022를 재현하는 `entries[].sizeBytes` 합계 규칙을 유지해 **258,074**로 갱신했다. 이 합계는 미등록 -v2 두 장을 세지 않으며 상한1,475,000은 유지했다.
