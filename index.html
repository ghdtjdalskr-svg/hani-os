Local/Cloud 기준이 불명확하거나 양쪽이 동시에 변경된 경우에는 자동으로 어느 쪽도 덮어쓰지 않습니다. Cloud → Local 반영 전에는 내부 안전 스냅샷과 read-back 검증을 통과해야 하며, hani_os_life_v23는 그대로 유지됩니다.

고급 설정 · 복구 도구
안전 원칙: 모든 입력은 먼저 이 기기의 localStorage에 저장·검증된 뒤 Cloud에 반영됩니다. 양쪽 기기에서 동시에 수정되면 자동으로 덮어쓰지 않고 충돌 상태에서 멈춥니다.
기준이 없는 기존 기기: Local과 Cloud가 다르면 한 번만 최신 쪽을 명시적으로 선택합니다. 이후에는 revision + durable-data hash 기준으로 자동 동기화됩니다.
🛡️ v2.9.18 Sync Core 진단확인 중
v2.9.12가 Cloud를 강제로 기준본으로 적용하기 직전에 저장한 브라우저 내부 안전 스냅샷을 확인합니다. 복구는 먼저 투자·자산 데이터만 Local에 병합하고, 화면 확인 후 별도 버튼으로 Cloud 기준본을 갱신합니다.
