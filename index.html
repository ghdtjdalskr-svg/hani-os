데이터 저장 상태

LOCAL
Phase 1에서는 기존 브라우저 데이터가 계속 원본입니다.
Cloud Bridge는 로그인과 최초 복사·검증만 담당하며, 자동 동기화나 Cloud → Local 덮어쓰기는 아직 하지 않습니다. JSON 백업과 hani_os_life_v23 localStorage는 그대로 유지됩니다.

HANI Cloud

CLOUD · 준비 중

🔐 새 비밀번호 설정 복구 링크가 확인되었어요. 아래에서 새 비밀번호를 정하면 됩니다.

고급 설정 · 복구 도구
