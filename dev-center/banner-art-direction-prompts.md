# HANI OS Unified Main Character Banner — Preview Asset Prompts

이 문서는 `hani/banner-art-direction-preview` 시안에서 사용한 신규 장면 생성 기준을 보존한다. 모든 장면은 2172×724, 3:1 비율로 제작했으며 Sports 승인 배너는 구성과 마감 수준만 참고했다.

## 공통 규칙

- HANI OS의 premium Korean webtoon illustration 스타일
- 왼쪽 약 38%는 UI 문구가 올라갈 수 있도록 차분한 여백 유지
- 인물과 핵심 소품은 오른쪽 약 62%에 배치
- 얼굴이 잘리지 않는 medium-wide framing
- 이미지 안에 로고, 이름표, 읽을 수 있는 글자, 숫자, watermark 금지
- canonical profile은 인물 정체성 참고용이며 배너 UI에서는 작은 avatar로만 사용

- **Props:** 절제된 시장 차트, 뉴스 티커 분위기, 태블릿, 종이 리포트
