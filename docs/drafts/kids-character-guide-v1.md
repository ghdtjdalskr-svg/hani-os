# 수현·수연 아동 캐릭터 기준안 v1 (2026-11-07, 하니 전무 정리 · 회장님 확정)

기준 이미지: `artifacts/companion-live/concept/kids-concept-v1.png` (도연 선임 시안). HANI OS·꽁트 이미지, 프로필, 표정/포즈 확장 시 이 표와 시안을 기본 레퍼런스로 쓴다. 꽁트 관계 설정은 Notion「HANI GROUP Story Canon · Family & Relationship Map」을 따른다. 회장님은 공식 개구리 캐릭터(애칭 금지).

| 구분 | 수현 | 수연 |
|---|---|---|
| 기본 인상 | 차분하고 반듯한 첫째, 조용하지만 든든함 | 밝고 애교 많고 감정 표현이 풍부한 사랑둥이 |
| 대표 컬러 | 블루/네이비 계열 | 코랄/핑크 계열 |
| 헤어/외형 | 브라운 숏헤어, 단정 | 브라운 양갈래, 밝고 귀여움 |
| 성격축 | 침착함 · 책임감 · 신뢰감 · 츤데레 | 활발함 · 애교 · 직진형 애정 · 장난기 |
| 기본 포즈 | 걷기 / 서 있기 / 앉아서 책 읽기 | 걷기 / 서 있기 / 앉아서 손 흔들기 |
| 회장님과의 관계 | 한 발 뒤에서 조용히 따라오며 챙김 | 바로 달려가 팔·몸에 착 붙고 안김 |
| 대표 감정 | 무표정, 살짝 웃음, 당황, 걱정, 츤데레 | 활짝 웃음, 삐짐, 애교, 신남, 울먹 |

- 메인 가족 컷: 수현 = 회장님 옆/뒤에서 조용히 따라오는 구도, 수연 = 회장님 팔이나 몸에 붙는 구도.
- 표정 대비: 수현은 "말보다 표정 변화가 작게 드러나는 타입", 수연은 "감정이 얼굴에 바로 나오는 타입".
