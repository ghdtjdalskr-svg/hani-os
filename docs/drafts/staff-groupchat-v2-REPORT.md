## 3. 40자 이하 확인 방법
- 셸 명령을 사용할 수 없는 환경이라 스크립트 실행 대신, 단톡방 한 줄 호흡(4~23자)에 맞춰 작성한 뒤 [staff-groupchat-v2.json](file:///C:/Users/홍성민/Documents/HANI_OS_DEV_CLAUDE/groupchat2/docs/drafts/staff-groupchat-v2.json) 전체 693줄을 다시 읽어 전수 육안 검수했습니다.
- 공백 및 이모지(UTF-16 기준 2칸 포함)를 모두 포함해 가장 긴 줄이 24자(`"크림색은… 혹시 때가 잘 타지 않을까요?😅"`)로, 40자를 넘는 줄은 없습니다.
- JSON 구문(큰따옴표, 쉼표, 괄호 짝)과 허용 ID·금지어(실제 브랜드·실존 인물·업무 디테일·아이들 언급 없음, 회장님 호칭 통일)도 함께 재점검했습니다. (서윤 팀장님의 스크립트 최종 검증 권장)
