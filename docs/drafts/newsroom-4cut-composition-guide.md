# 뉴스룸 주간 4컷 구도 가이드

1200×2000 세로 4단, 기존 캐스트·그림체·보라색 테두리를 유지한다. 컷마다 인원 수, 카메라 높이, 인물 크기와 말풍선 수(1~3개)를 달리한다. 전원 가로 정렬을 기본값으로 쓰지 않는다.

| 주간 상황 | 구도 레퍼토리 | 표정·연출 |
|---|---|---|
| 급등 | 낮은 시점의 상승 계단 전신 → 전광판과 눈 클로즈업 → 위에서 보는 상승 지도 → 정면 앵커 | 놀람·기쁨·신중함. 상승을 매수 권유로 표현하지 않는다. |
| 급락 | 경고 전광판과 앵커 클로즈업 → 하강 미끄럼틀·난간 전신 액션 → 국가별 낙폭을 보는 부감 지도 → 어깨 너머 준비 회의 | 놀람·진땀·결의·차분한 미소. 하락·지지선은 비유이며 수치는 자막으로 명시한다. |
| 횡보 | 옆모습의 줄다리기 → 위에서 보는 평평한 차트 → 창밖을 보는 뒷모습 → 책상 위 지표 클로즈업 | 망설임·관찰·집중. 움직임이 작아도 인물 배치와 시점은 바꾼다. |
| 이벤트 주간 | 달력·시계 접사 → 발표 화면과 기자의 분할 구도 → 결과 자료를 보는 어깨 너머 → 독자에게 정면 마무리 | 긴장·놀람·숙고. 예정과 발표 완료를 구분한다. |

- **같은 구도를 2주 연속 쓰지 않는다.** 직전 호와 네 컷의 시점·인원 배치·중심 소품을 비교해 반복되는 컷은 다시 설계한다. 같은 상황이어도 다른 레퍼토리를 택한다.
- 생성 전에 컷별 상황 / 앵글 / 주인공 / 동작 / 표정 / 말풍선 수를 한 줄씩 정한다. 클로즈업·전신·부감·뒷모습 중 최소 세 가지를 섞는다.
- 주간 수치·종가·환율·고용 등 필수 숫자는 아래 자막에 모두 정확하게 넣는다. 일간과 주간, 기준일·시각을 혼동하지 않는다.
- 생성본과 최종 WebP의 한글·부호·소수점·쉼표를 확대 대조한다. 1호/직전 시안/새 시안 비교와 PC1280·폰390 화면을 확인한다.
- 하단 `※ 정보 정리용이며 투자 권유가 아닙니다.`를 보존한다. 캐스트 추가는 해당 참조·승인 범위를 따른다.

2호 새 시안(2026-11-08): 하니 경고등 클로즈업(1개) → 지은 난간 액션(2개) → 민지 지도 부감(1개) → 어깨 너머 고용지표 회의(2개). 다음 호는 이 순서와 배치를 반복하지 않는다.
