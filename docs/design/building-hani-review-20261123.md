# 하니 전무 의견 — 하니 그룹 대공사 (2026-11-23)

회장님이 받아 서윤에게 전달함. 3~5단계 설계의 기준 문서로 사용.

## 결론
- 전체 방향 유지, 대규모 수정 불필요.
- 4단계 최우선: **성격 행동 + 관계 기반 희귀 장면**. "이동량 증가"가 아니라 "개성이 행동으로 보이게".
- 성공 기준: **"같은 시간대에 일주일 동안 들어가도 매일 다른 회사처럼 보인다." / "저 행동은 저 사람답다."**
- 층 성격: 5F = 활동 · 6F = 기억 · 7F = 계절·감정 이벤트.
- 회장님 개입 우선순위: ① 직접 걷기 ② 직원에게 말 걸기 ③ 식빵 산책 ④ 장소 이벤트 열기. 처음에는 저장 없는 조작.
- NPC: 얕고 명확하게.

## 1. 직원별 성격 행동 (장소를 가는 "이유"가 성격과 연결)
| 직원 | 자주 가는 곳 | 이유·행동 |
|---|---|---|
| 히나 | 5F 도서관·간식 공간 | 공부하다 간식으로 샘 |
| 민지 | 방송 스튜디오·시네마·옥상 | 기록·촬영·콘텐츠 소재 탐색 |
| 나은 | 피트니스·키즈·펫 | 직원 상태·아이들 챙기기 |
| 세린 | 자료 공간·화이트보드·도서관·옥상 | 생각 폭주, 아이디어 정리 |
| 아린 | 스튜디오·전시·라운지 | 화면·디자인·배치 관찰 |
| 유리 | 개발실·박물관·기록물 | 검증 안 된 설명·결과 체크 |
| 서윤 | 3F 고정 X → 4F 전략기획실·5F 스튜디오 | 실제 사용 맥락 보기 |
| 수현·수연 | 자유 행동 유지 | 직원들과 상호작용 확대 |

엔진 입력: 캐릭터별 장소 선호 + 시간대 + 관계 seed + 최근 행동 이력.

## 2. 희귀 장면 (관계가 드러나는 장면, 주 1~2회 체감, 연속 금지 쿨다운)
- 하니·서윤: 늦은 밤 4F 라운지 로드맵 검토
- 히나·윤슬: 도서관에서 공부하다 둘 다 딴 책 읽기
- 유리·아린: "예쁨 vs 정확함" 티키타카
- 민지: 옥상에서 몰래카메라 찍다 하니에게 걸림
- 수현·수연: 퇴근 직전 회장실에 아빠 데리러 옴
- 식빵: 회장님 말고 다른 직원을 따라가 버림
- 나은: 야근 직원 발견 → 강제 휴식 시도
- 지은·하루: 편의점 영수증 소비 추적 실랑이

## 3. 층 성격
- **5F 라이프·크리에이티브(활동)**: 방송 스튜디오(일보·특집·퀴즈·촬영) / 도서관(윤슬·히나·세린) / 피트니스(나은·수연) / 키즈·펫(수현·수연·반려동물) / 시네마(민지).
- **6F 박물관(기억)**: 회장님 마일스톤, 입사 기록, 역대 퀸, 일보 표지, 4컷, 배포 연표. 단순 전시가 아니라 **직원이 과거 기록을 보고 반응하는 장소**.
- **7F 옥상(계절·감정)**: 첫눈, 야경, 생일, 불꽃놀이, 야근 후 휴식, 계절 행사, 조용한 대화 희귀 장면.

## 4. NPC 7명 (호감도·투표·저장 없음, 조직도 제외, 한 줄 성격)
역할: HANI 24 주간 점원 / HANI 24 야간 점원 / 카페 바리스타 / 박물관 학예사 / 시설관리 / **방문객 안내(1F 프론트)** / 택배·배송.
예: 주간 점원 = 밝고 수다스러움 · 야간 점원 = 무표정하지만 챙겨줌 · 학예사 = 차분한 기록 덕후.
이름: 짧고 기억하기 쉬운 한국 여성 이름.

## 5. 회장님 개입 반응 예
- 늦은 밤 말 걸기 → "아직 계셨어요?"
- 식빵과 함께 가면 직원이 식빵부터 반응
- 5F 스튜디오 접근 → 촬영 이벤트
- 7F 옥상 → 계절 이벤트
위치·시간·직원 상태에 따라 짧은 반응이 달라지게.

## 6. 행동 엔진 핵심 요소
장소 선호 · 시간대 행동 · 관계 seed 동행 · 최근 방문 쿨다운 · 같은 행동 반복 방지 · 1인/2인/드문 3인 구분 · 관계 조합 희귀 장면 · 7일 시뮬레이션 반복도 검사. 관계는 숫자 호감도 없이 행동 빈도에 반영.

## 7. 스케이트 걸음
4단계에서 이동 속도 · 보폭 · 다리 모션 · 정지 타이밍을 함께 맞춤.
