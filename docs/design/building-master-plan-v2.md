## 0. 회장님용 쉬운 요약 5줄 & 결정 목록

### 0.1 회장님용 쉬운 요약 (5줄)

1. **1층을 로비·편의점·카페 전용 공용층으로 바꾸고**, 1층에 있던 기업솔루션사업부(수아·채원)를 위층(추천: **2층 여유석** 또는 별도 층)으로 옮겨 회사 구성을 현실적으로 재정비합니다.
2. **편의점 점원·경비·스튜디오 스태프·트레이너·사서·손님 등 NPC를 추가**해 층마다 살아 움직이는 복작복작한 회사를 만들되, **직원 명부·친밀도·퀸 투표 데이터와는 완전히 분리**합니다.
3. **수현·수연 남매가 사랑받는 비결(다층 리듬·서로 반응·희귀 대사·예측 불가성)**을 일반 직원들에게도 적용해, 성격·관계·사내 이벤트(일보·배포·생일)에 반응하는 **무저장·0원(AI 호출 0) 살아있는 행동 엔진**을 구축합니다.
4. **공식 개구리 회장님 캐릭터를 직접 움직여** 직원·NPC에게 말을 걸거나 간식·칭찬 이벤트를 열고, **부서별 심볼 로고**·캐릭터 일과 보기·희귀 장면 도감 등 **제대로 된 RPG 감성**을 입힙니다.
5. 한 번에 다 고치지 않고 **5번의 작은 배포(뼈대 → 5F/6F → 1F 편의점·이동 → 행동/NPC → 회장님 조작/RPG)**로 안전하게 쪼개어 진행하며, 저장이 필요한 신규 기능은 반드시 회장님 별도 승인을 받습니다.

### 6.2 직원 행동 고도화 4대 축 (무저장 · 0-AI 토큰 · KST 결정적)

#### ① 성격·직무·일과에서 나오는 '시퀀스형 고유 행동 (Micro-Arcs)'
단순 1문장 혼잣말을 **2~3단계 동작+이동+대사 연결 시퀀스**로 확장합니다(별도 AI 호출 없이 `place` + `state` 조합):
- **민지 (콘텐츠)**: 5F 스튜디오 카메라 점검(`standing`) → 1F/2F 동료에게 촬영 포즈 요청(`approach`) → 자기 자리로 돌아와 사진 고르기(`"방금 찍은 컷, 오늘 일보 썸네일 감이다!"`).
- **나은 (건강)**: 2F 자리에서 기지개(`standing`) → 5F 피트니스 러닝머신(`walk`) → 1F 편의점에서 프로틴/생수 확인 → `"오늘 수분 섭취량 체크 완료!"`.
- **다온 (리스크)**: 2F 자리에서 우려 메모 → 1F 카페에서 지은에게 질문(`"부장님, 최악의 경우 시나리오 하나만 더요😅"`) → 안도 한숨.
- **도연·세린 (개발)**: 3F 서버실 콘솔 확인 → 1F 편의점 야식 컵라면 → 3F 스탠드업 화이트보드 메모.
- **수아·채원 (기업솔루션)**: 2F(안1)에서 제안서 정리 → 1F 로비 상담부스에서 고객 미팅 → 완료 후 1F 카페에서 잠깐 숨 돌리기.
