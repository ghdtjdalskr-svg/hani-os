## 변경

HANI AURA를 최상위 메뉴에서 성민 오피스 하위 메뉴로 옮기고, 배포센터를 업무/시스템 그룹으로 이동했다. 변경 파일은 `hani-main.js`, `index.html` 두 개다. 보호 데이터 구조, Cloud schema와 인증 경로는 이 변경 범위에 없다.

## P0 확인 결과

- P0 브랜치 생성 후 `origin/main`이 v2.9.164에서 위 v2.9.165 SHA로 이동한 사실을 확인했다.
- GitHub Pages index가 HTTP 200으로 v2.9.165를 표시하고 `hani-main.js?v=2.9.165`를 참조했다.
- 실제 Pages의 `hani-main.js?v=2.9.165`도 HTTP 200과 v2.9.165 내용을 반환했다.
- `hani-ui-v02992.js`는 이 릴리스 변경 대상이 아니어서 기존 `?v=2.9.164` 참조를 유지한다.
- 후보 단계의 1440px/390px 메뉴·클릭·모바일 사이드바 검사는 기존 작업 기록에 PASS로 남아 있다.
