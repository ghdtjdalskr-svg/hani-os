# 작업 인수인계 양식

`handoffs/<날짜>-<작업>.md`로 복사해 작성합니다. 미확인 칸은 미확인으로 남깁니다.

## 작업 식별

- 작업 ID / 제목:
- 갱신 시각(KST):
- 담당 도구 / 검토 담당:
- 상태: 예정 / 진행 중 / 검증 대기 / 승인 대기 / main 병합 / Pages 확인 / 운영 read-back 완료 / 보류
- 저장소 / branch / worktree:
- base SHA / candidate SHA:
- 목표 / 완료 조건:
- 수정할 파일·범위 / 다른 담당과 겹치는 범위:
- 사용자 승인 근거 / 승인되지 않은 경계:

## 결과와 증거

- 변경한 내용 / 파일:
- 실행한 검증: 항목, 결과, 환경, 대상 SHA, 증거 위치
- 실행하지 않은 검증 / 남은 위험:
- 데이터·저장소·Cloud·schema 영향:
- PR / Preview / 배포 원문 링크:
- main / Pages / 표시 버전 / 실제 JS 로딩 / 기능 read-back: 단계별 확인 또는 미확인

## 다음 담당에게

- 먼저 읽을 파일·관련 함수:
- 다음 한 가지 행동:
- blocker / 필요한 사용자 결정:
- 다른 작업에 영향을 주는 사항:
- CURRENT / DECISIONS 갱신 내용:

실행하지 않은 검사는 PASS로 쓰지 않습니다. commit·문서 공유는 배포 승인이 아닙니다. Production 완료는 모든 read-back 단계의 증거가 있을 때만 기록합니다.
