## 목적

종목과 보유수량 중심으로 계좌를 안전하게 업데이트하면서, 원가를 모르는 경우 값을 추정하지 않고 부분 입력 때문에 기존 종목이 매도된 것으로 오해되지 않도록 입력 계약을 명확히 한다.

## 변경

- 평균매입가는 선택 입력이다. 값이 없으면 평가액은 현재가로 계산할 수 있지만 원가·손익·수익률은 제공하지 않는다.
- 평균매입가를 입력한 경우에만 KRW/USD 매입 통화를 필수로 확인한다.
- 기본 입력 범위는 `partial`이며 목록에 없는 기존 종목은 그대로 유지한다.
- `complete`는 기존 활성 종목을 모두 목록에 포함하고 “현재 전체 보유목록” 확인을 거쳐야 저장된다.
- 매도는 해당 종목을 목록에 남긴 채 `quantity=0`으로 명시한 경우만 표현한다. 누락만으로 자동 매도하지 않는다.
- 종목 매칭은 `instrumentId → ticker → name` 순서를 사용한다. 기존 canonical 종목명·ticker·시장 값은 OCR 또는 임시 입력으로 덮어쓰지 않는다.
- 새 보유정보 기록에는 `holdingListMode`를 snapshot과 account에 함께 남긴다. 이전 기록은 소급 추정하지 않고 `UNKNOWN`으로 읽는다.
- Portfolio의 가격 연결 범위와 보유목록 완전성을 별도 상태로 표시한다.

- Supabase write와 Cloud schema는 변경하지 않는다.
