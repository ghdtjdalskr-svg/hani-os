### 3. 이동 구역·경로와 상태 전이

보행은 `현재 앵커 → 실내 측면 통로 → 방 문 → 층 복도 → 승강기/계단 → 목적층 복도 → 방 문 → 목적지`입니다. 예를 들어 `arrival_gate → door_lobby → hall_lobby → hall_1f → elevator_1f → elevator_2f → elevator_3f → elevator_4f → hall_4f → hall_ceo → door_ceo → junction_ceo → approach_ceo_desk → side_ceo_desk → ceo_desk`를 사용합니다. 경로 탐색은 간선 수 기준 최단경로입니다. 다른 사람의 좌석을 지름길로 사용하지 않습니다.

`walk/door/seat/elevator/stairs` 간선을 구분합니다. 마지막 `seat`만 가구 측면에서 착석 기준점으로 진입합니다. 문은1인, 승강기는4인, 회의석은6인 정원 규격입니다. 좌석별 slot을 예약하며 만석은 문 앞 FIFO 대기가 최종 설계입니다. 데모는 좌석 slot 분리·만석 시 이동 중단까지 구현했고 문/승강기 동시 예약·FIFO는 미구현입니다. 방문 NPC는 공개 1F와 상담실만 이용하며 다른 층은 직원 동행이 필요합니다. 프로토타입에서 NPC 보행과 서버실 접근 제어는 구현하지 않았습니다.

상태는 `Arrive, Work, Walk, Meeting, Coffee, Lunch, Rest, Client, Away, Overtime, Leave` 11개입니다. 전체 허용 전이는 JSON `states`에 있습니다. 보통 `Away→Arrive→Walk→Work`, `Work→Walk→Meeting/Coffee/Lunch/Rest/Client→Walk→Work`, `Work→Overtime→Walk→Leave→Away`를 사용합니다. 회의에서 좌석으로 즉시 순간이동하지 않습니다. 외근/숨김은 `Away`로 중단하고 예약을 해제합니다. 경로 실패는 출발 앵커 유지·사유 표시입니다.

### 4. 일과 초안과 결정적 변주

### 6. 성민 회장님 재실과 첫 방문

active는 visible 상태에서 최근 pointer/keyboard/touch 입력이5분 미만인 경우입니다. 회장실에 착석하고 불이 켜집니다. idle5분 또는 문서 hidden이면 인물을 숨기고 불을 끕니다. KST08:00~18:00는 「외근 중」, 나머지는 「퇴근」입니다. 첫 방문은 KST 날짜를 메모리 Set으로 구분하고 총2.6초에 `gate(0)→elevator_1f(400ms)→elevator_4f(1250ms)→door_ceo/불(1900ms)→ceo_desk(2600ms)`를 목표로 합니다. 층간 중간 간선을 모두 지나는 압축 동선입니다. 이동 감소 설정에서는 즉시 최종 위치/텍스트로 정리합니다. 실제 브라우저의2~3초 타이밍은 EPERM으로 미검증입니다.
