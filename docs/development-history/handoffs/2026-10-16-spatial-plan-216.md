### 4 Walkable / No-walk zones

각 floor.walkable에서 floor.noWalk를 제외한 공간만 걷는다. 책상 표면·회의 테이블/소파 표면·벽·MIR pod/core는 no-walk다. 의자 발 앵커는 표면 밖에 있고 마지막 seat 간선으로만 접근한다. 문 개구부 외 벽 통과, 좌석 지름길, 자유 좌표 목적지를 허용하지 않는다.

현재 계약: 326개 앵커 / 328개 간선. 새 좌석 주변 경로는 설계 단계에서 장애물을 피하는 고정 꺾임 앵커로 생성했다. prototype은 이 그래프만 따라간다. 2px 간격으로 모든 같은 층 경로 선분의 no-walk 비통과와 문/보행 구역을 검사한다. 승강기/계단만 인접 층을 연결한다. 문1인/승강기4인 FIFO와 실시간 혼잡 예약은 후속이며 이번에 구현했다고 보고하지 않는다.

### 5 MIR Station detail

- 4F mir_nook 안의 전용 작은 원형 console/pod. Pearl #F6F4EF / Silver #BCC6CF / Pale Cyan #DDF6FA.
- mir_station: 미르의 홈·업무·기본 서기 지점. 고정 책상 복제 금지. 선택 착석은 향후 pod 전용 원화/anchor 확정 때만 추가.
- mir_core: pod의 작은 고정 AI 빛 오브젝트, 보행 목적지 아님. 선택 벽/소형 display 가능. 별도 인물 슬롯이 아니므로 미르를 복제하지 않는다.
- mir_meeting_pos: 임원회의실의 미르 지정석, 215 context-side ID를 renderer slot으로 재사용. home은 계속 mir_station이다.
- 평시 자료 보기 / 관찰 / 생각하기를 KST 날짜+5분 slot hash로 선택. 회의 버튼에서 실제 그래프 이동 후 착석, 전원 복귀에서 Station으로 돌아와 서기. 회의석과 Station에 동시에 나타나지 않는다.
- 특별 이벤트는 승인된 목적지 방문 가능, 옥상 휴식은 선택 사항. 화면 전용 인물이 아니며 API로 이동/대사를 생성하지 않는다.

### 6 Sitting/Standing/Walking layer rules

215의 persistent actor slot과 seatActor owner를 후속 운영 구현에서도 유지한다. 새 event/renderer layer를 덧붙이지 않는다. 215 layer4/desk8/앞 회의석9는 원화 전용 수치로 보존하고 V2는 발 y 깊이·자기 가구 mask를 사용한다. 이 차이는 새 원화와 함께 기존 renderer에서 조정할 후속 사항이다.

서기: 발은 보행 가능 앵커, MIR Station에서 서며 pod와 분리. 앉기: 명명 좌석 하나당 인물 하나, 의자 후경 → 인물 → 자기 책상 전경/의자 앞면 순서. 걷기: Walk 상태에서 간선 보간, 바닥 그림자와 발 y로 정렬하며 가구를 관통하지 않는다. 인물이 책상 앞을 걸을 때 모든 책상을 무조건 최상단에 올리지 않는다. MIR도 독자 이동 인물 atlas를 사용하고 core light만 고정 소품이다. 이름·방 표기는 HTML overlay다.

### 7 Daily state map

기본 Away → Arrive → Walk → Work. 휴식/회의/고객/점심은 Work → Walk → 해당 상태 → Walk → Work. 퇴근은 Walk → Leave → Away. 집/홈 소속과 현재 행동 위치를 섞지 않는다.
