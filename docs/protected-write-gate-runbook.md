# 강화된 보호 저장 게이트 · 개발 후보

성민 대표님이 2026-10-05에 개발·검증을 승인한 범위입니다. 운영 반영 승인은 포함하지 않습니다.

## 기본 차단 유지

게이트 계약 버전은 2.0.6, 로컬 Pre-QA 도구는 0.4.0입니다. 서버·로컬의 계약 hash가 일치해야 하며 기존 2.0.5 운영 서버에 이 후보 패키지를 등록하지 않습니다.

승인 정책이 없으면 기존 호출 개수 비교를 그대로 적용합니다. 키·내부 버전·원본 쓰기 2곳/삭제 1곳/clear 없음, 전체 모듈의 hani_state 호출 6곳을 유지합니다. hani-main.js 단독 호출은 5곳이며 나머지 1곳은 기존 모듈의 읽기 경로입니다.

서버가 읽는 `HANI_PROTECTED_WRITE_APPROVAL`, `HANI_PROTECTED_WRITE_EVIDENCE`는 서버 설정 전용입니다. 요청 본문·저장소 보고서·클라이언트 값은 승인 근거가 아닙니다. 테스트용 합성 정책은 실제 승인으로 등록하지 않습니다.

## 검증 근거와 후보 결합

동결한 commit의 파일 바이트로 전체 패키지를 만들고, 모든 패키지 파일을 원본 commit과 직접 비교합니다. 실행 생성기는 그 바이트를 별도 가상 실행 폴더로 복제해 검사합니다. 원본 작업 폴더의 개인 생활 기록이나 인증 세션을 쓰지 않습니다.

필수 실행군은 원본 보호 28건, 백업 11건, 화면 6건, 실제 거래 handler 1건, owner handler 2건, 부정 게이트 19건입니다. 추가 서버/로컬 통합 12건도 실행합니다. 어느 하나 실패하면 보고서를 FAIL로 기록하며 다음 실행군으로 자동 넘어가지 않습니다.

보고서는 기준 main SHA, 소스 후보 SHA, 서버와 동일한 순서의 런타임 SHA-256, 전체 패키지 SHA-256, 각 검사 파일·실행 출력 SHA-256, 변경 파일 SHA-256을 기록합니다. 보고서 파일 전체 해시도 승인 정책에 고정합니다. 키/버전/쓰기 표면, 기준선, 소스, 이미지 등 패키지, 증거 또는 유효기간이 다르면 차단됩니다.

로컬 Pre-QA는 `--protected-package`와 서버 설정과 동일한 **별도로 검토·등록된** 정책·증거가 있을 때만 계약을 평가합니다. 보호 계약이 통과한 경우에도 저장/키/이벤트 검토 finding의 모든 파일이 증거의 변경 파일 해시 및 후보 commit과 일치해야 합니다. 그 세 검사 외의 범위·비밀정보·Cloud mutation·파괴적 동작 검사는 계속 유지합니다. Worktree dry run에는 이 허용을 적용하지 않습니다.

## 운영 등록 전 순서

1. 최종 후보 freeze → package byte 검증 → 격리 실행 보고서 생성.
2. 독립 HINA 검토 및 성민 대표님의 **정확한 후보·패키지·증거** 승인.
3. 서버 owner 계정 설정을 확인합니다. owner 설정이 없으면 이 서버 후보는 모든 사용자를 거부합니다.
4. 검토 완료한 정책의 승인 ID·만료시간을 지정해 서버에 등록합니다. 생성기가 내놓는 정책은 PENDING_REVIEW이며 등록 가능한 승인값을 자동 만들지 않습니다.
5. 제어 코드의 배포 승인·등록, 실제 서버 Gate·소유자 인증 read-back, 사이트 후보의 최종 Preview 승인과 기존 release flow를 수행합니다.

서버 업로드는 파일별 commit을 새로 만들므로 소스 commit SHA와 업로드 head SHA가 다를 수 있습니다. 승인 소스와의 내용 동일성은 전체 런타임 및 패키지 해시로 확인하고, 기존 업로드 read-back·최종 head 동결·merge 직전 HINA 재검사는 유지합니다. 승인 이후의 수정은 기존 증거를 재사용하지 않습니다.

## 되돌리기

정책 또는 증거 설정을 제거하면 호출 개수 변경 후보는 다시 기본 차단됩니다. 제어 코드 되돌리기는 기존 Function 버전으로 복구하는 별도 배포입니다. 생활 원본·백업 사본·Cloud schema를 삭제하거나 초기화하지 않습니다.

실제 서버 설정과 운영 배포는 아직 수행하지 않았습니다. 개발 검증 통과를 운영 HINA PASS로 기록하지 않습니다.
