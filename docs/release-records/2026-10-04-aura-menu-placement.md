# HANI AURA · 메뉴 분류 변경 — v2.9.165 배포 완료

## 목적과 결정

성민 대표님 요청에 따라 HANI AURA를 대시보드와 동급인 최상위 메뉴에서 성민 오피스의 하위 메뉴로 이동한다. 배포 센터는 업무 / 시스템 하위로 이동한다.

포스터의 감성을 유지하면서 크기만 줄이고, 계절 선택도 미니 포스터 형태로 개선하는 방향은 별도 후속 구현으로 남아 있다. 이번 변경에 포스터 개선이 포함되었다고 표시하지 않는다.

## 실제 변경

- index.html의 기존 메뉴 버튼을 재배치했다. AURA는 일반 하위 메뉴 형태를 사용한다.
- 성민 오피스 설명에서 배포 대신 AURA를 안내한다.
- 기존 #aura / #deployment 주소, 공통 메뉴 클릭 경로와 배포 버튼의 연결을 유지한다.
- 데이터 저장, Cloud, schema, 인증, 배포 절차와 관련 JS는 변경하지 않는다.
