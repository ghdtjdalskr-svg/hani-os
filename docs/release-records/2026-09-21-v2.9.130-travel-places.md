## 완료 내용

- 여행과 관계없이 맛집·카페·명소·숙소·쇼핑·기타 장소를 독립 등록할 수 있게 했다.
- 장소별 방문일, 위치, 별점, 비용, 대표 메뉴·볼거리, 가격대, 재방문 의사와 후기를 기록한다.
- 기존 여행 후기와 독립 장소를 `맛집 & 명소` 목록에서 함께 표시한다.
- 카테고리·연결 여행 필터, 최근 방문·평점·이름 정렬, 장소 검색을 제공한다.
- 여행 일정 붙여넣기 미리보기에서 실제 방문한 행을 선택하면 해당 여행의 장소 목록에도 연결한다.
- 여행 삭제 시 독립 장소 기록은 보존하고 여행 연결만 해제한다.
- 데스크톱 가로 목록과 모바일 카드형 화면을 적용했다.

- 보호 키 `hani_os_life_v23`의 이름을 변경하거나 삭제하지 않았다.
- 내부 데이터 기준 버전 `2.9.15-safe-baseline-bootstrap`을 유지했다.
- 기존 저장 상태에 하위 호환 가능한 `travelPlaces` 배열을 추가했다.
- 기존 canonical 저장 경로를 재사용했으며 새로운 `localStorage.setItem`, `removeItem`, `clear` 호출은 추가하지 않았다.
