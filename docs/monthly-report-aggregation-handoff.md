# 월간보고 읽기 전용 집계 개선

- 기준: main `d47ae3808af1a60b95dafb58dbab9e214a0e1095`, 운영 v2.9.141.
- 작업 브랜치: `hani/monthly-report-aggregation`.
- 소유 경로: `hani-main.js`의 기존 monthlyReport 함수와 renderAll 호출. 신규 렌더러/이벤트 레이어 없음.
- 범위: 월간보고 전용 읽기 어댑터. 기존 입력, 저장, Cloud 및 스키마 변경 없음.

## 적용 기준

- 운동/체중은 날짜별 최신 갱신값 하나로 집계. 갱신시각이 같거나 없으면 저장 배열의 마지막 기록을 사용한다. 원본 행은 그대로 유지하며 중복 축약 사실을 화면에 표시한다.
- 운동 기록일과 양수 걸음 관측일을 구분. 걸음 미입력·0·음수는 걸음 평균에서 제외한다. 거리는 유효한 양수 관측값만 합산하며 미관측이면 기록 없음으로 표시한다.
- 체중은 양수 측정값만 사용하며 첫 측정 대비 변화와 실제 측정 날짜를 표시한다.
- 시청 완료 입력 1건은 1건으로 센다. 회차/시리즈 묶음은 건수를 늘리지 않는다.
- 완독일은 completedDate/readDate를 지원한다. 날짜 오류나 두 날짜의 충돌은 임의 추정하지 않고 제외한다.
- 엄격한 달력 날짜 검증 및 한국시간 기준 미래 실적 제외. 퀴즈는 시간대가 명시된 completedAt 기준으로 월을 나눈다.
- 학습은 완료 세트 수와 신뢰 가능한 total/correctCount의 문항 합계를 표시한다. 점수로 정답 수를 역산하지 않는다. 채점 수치 포함 범위를 함께 표시한다.
- 투자는 해당 월의 과거/현재 확정 실제 스냅샷만 사용한다. 현재 투자 목표를 과거에 소급 적용하지 않는다.
- 소비는 기존 ledgerCalc 계산을 유지하며 유효한 날짜의 비미래 항목만 전달한다. 저장 결산기간 또는 전월 18일~당월 17일을 명시한다.
- 할일/대학은 집계하지 않는다.

## 개발 검증

- Node syntax 및 집계 회귀 테스트: 날짜/윤년, 한국시간 경계, 미래 실적, 날짜 중복, 양수 걸음 분모, 시청 건수, 완독일 호환/충돌, 가중 정답률, 역사적 목표 분리, 결산기간, 원본 전체 freeze 불변 검사.
- 기존 Playwright smoke 확장: 1440/390 화면, 합계와 문구, 월 변경, 빈 월, 저장값 동일, 가로 overflow 검사. 고정 테스트 시각 2026-09-30.
- 스크린샷: artifacts/monthly-report/desktop.png 및 mobile.png. 전체 화면 캡처에 기존 공통 플로팅 바/리모컨이 겹치므로 해당 공통 UI는 이번 변경의 시각 PASS 대상으로 주장하지 않는다. 보고 도메인 여섯 개의 배치와 문구를 확인했다.
