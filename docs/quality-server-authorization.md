# D02 · 서버 소유자 제한

개발 기준: main `69ea05d` / v2.9.175. 운영에는 아직 반영하지 않았습니다.

두 Edge Function은 `auth.getUser()`로 검증한 사용자 ID를 서버 환경의 `HANI_OWNER_USER_ID`와 비교합니다. 사용자 메타데이터는 권한 근거로 쓰지 않습니다. 누락 설정은 503, 다른 계정은 403으로 거부하며 외부 작업 전에 멈춥니다. 설정값·토큰을 저장소나 로그에 기록하지 않습니다.

배포 전 순서: 소유 계정의 검증된 ID 확인 → 두 Function의 서버 환경 설정 → 설정 존재 확인 → 서버 후보 검증 → 대표 승인 → 배포 → 소유 계정 허용/다른 계정 거부 read-back. 설정이 없는 상태로 먼저 배포하면 대표 계정도 잠깁니다.

가상 인증으로 실제 두 handler의 소유자/다른 사용자/설정 누락/인증 실패와 기존 입력 검증 진입을 확인했습니다. 운영의 가입 허용 정책, 현재 사용자 명단, 환경 설정은 미검증입니다. 공개 회원가입 정책 변경과 사용자 삭제는 이번 구현에 포함하지 않습니다.

롤백은 이 두 Function의 이전 소스 재배포이며 사용자 데이터나 DB schema를 바꾸지 않습니다. 운영 배포와 환경 변경은 별도 승인·최종 QA 대상입니다.
