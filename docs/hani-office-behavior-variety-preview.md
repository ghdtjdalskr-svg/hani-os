# HANI OFFICE LIVE · 행동 다양화 Preview

기존 Living Office와 회의 동선을 유지하면서 평상시 행동만 조정한다.

- HANI: 전용실을 기본 위치로 유지하고 가끔 직원석 사이 통로로 나와 사무실을 둘러본다.
- NAEUN: 지정석 건강 기록·컨디션 메모, 직원석 사이 안부, 커피·소파·유나와의 대화를 순환한다.
- JIEUN, HINA, SUA, HARU, MINJI, SOOYEON, YUNA에도 역할에 맞는 업무 행동을 한 가지 이상 보강한다.
- 한 번에 소수 인원만 움직이는 기존 순환과 fixed spot 구조를 유지한다.
- Agenda가 제출되면 평상시 순환을 멈추고 기존 Summon/Meeting 흐름을 우선한다.

이 파일은 Front Preview다. Agent Logic, DB, Supabase, localStorage, Production 파일을 변경하지 않는다.
