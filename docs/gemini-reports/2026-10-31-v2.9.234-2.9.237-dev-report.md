## 내가 실제로 체감하는 변화

- **v2.9.234**: 공식 개구리 회장님 캐릭터를 등장시키고 본사 행동을 다듬었습니다.
- **v2.9.235**: 마일스톤의 치비 수집 카드를 넣고 가계부·자산 화면을 복구했습니다.
- **v2.9.236**: 본사의 활기·이름표·회장님 인사와 마일스톤 카드를 다듬었습니다.
- **v2.9.237**: 어두운 테마에서 글자 대비와 화면이 깨지는 문제를 수정했습니다.

## 왜 바꿨나요?

공개용 제목과 관련 인수인계를 바탕으로 정리한 목적입니다. 원문에 없는 효과를 검증 완료로 판단하지 않았습니다.

- **v2.9.234**: 성민 회장님도 직원들과 같은 본사 장면에서 알아볼 수 있도록 구성했습니다.
- **v2.9.235**: 삶에 남은 변화를 모아 보는 즐거움과 기존 화면의 사용성을 함께 회복하려는 변경입니다.
- **v2.9.236**: 누가 무엇을 하는지 알아보기 쉽게 하고 주요 변화를 카드로 확인하도록 정리했습니다.
- **v2.9.237**: 테마를 바꿔도 글을 읽고 기존 화면을 사용할 수 있게 하기 위한 변경입니다.

- **v2.9.234**: 로컬 Git 커밋 제목·본문 확인(PR 본문은 커밋에 남은 부분만). 연결할 인수인계 미확인.
- **v2.9.235**: 로컬 Git 커밋 제목·본문 확인(PR 본문은 커밋에 남은 부분만). 연결할 인수인계 미확인.
- **v2.9.236**: 로컬 Git 커밋 제목·본문 확인(PR 본문은 커밋에 남은 부분만). [인수인계 2026-10-31](../development-history/handoffs/2026-10-31-milestones-launch.md)

## 아직 남은 것

- **v2.9.234**: 표시 캐릭터가 실제 업무를 수행했다는 뜻은 아닙니다. 장면별 겹침과 움직임은 별도 확인이 필요합니다.
- **v2.9.235**: 수집 카드의 표시와 원래 기록의 보존은 구분해야 하며, 실제 기기의 상세 열람은 배포 근거를 확인해야 합니다.
- **v2.9.236**: 공개 보고서에는 개인 건강 목표나 달성 수치를 싣지 않았습니다. 개별 달성 판정은 원래 화면에서 확인해야 합니다.
- **v2.9.237**: 모든 화면과 실기기의 대비를 이번 보고서 작성에서 재측정하지 않았습니다.
- 이번 문서 작성에서는 운영 화면·실기기·서버·데이터 저장을 재검증하지 않았습니다. 실제 운영 상태는 배포 담당자의 확인 기록을 따릅니다.

## 데이터나 안전에 영향이 있나요?

- 보고서 생성은 문서와 문서 목록만 씁니다. 앱의 생활 기록·Cloud·설정·런타임 코드는 변경하지 않습니다.
- 개인 생활 원본과 원문 로그를 싣지 않고 공개용 변경 설명과 문서 참조만 담았습니다.

## 회장님이 알아둘 점

- 새 원고는 검토 대기입니다. 파일 추가만으로 앱에 표시되지 않으며, 서윤 팀장의 릴리스 후속 tooling에서 기존 보고서 번들 반영을 따로 검토해야 합니다.
- 역할 안내: 하니 전무님은 방향 조율, 서윤 팀장(M9 특별 합류)은 후속 tooling, 도연 선임은 구현, 세린 연구원은 보고서 문체, 유리 책임은 품질 검토의 참고 역할입니다. 이번 문서를 이들이 작성·검수했다는 뜻은 아닙니다.
