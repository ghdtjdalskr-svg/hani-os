## 왜 바꿨나요?

열차 1호는 v2.9.180에서 누락된 기능의 회귀를 수정했습니다. 열차 6호에는 안정화 핫픽스와 대시보드 월 1회 입력 기준이 포함되었습니다. 다른 항목의 구체적인 기획 배경은 기록에서 확인되지 않습니다.

## 데이터나 안전에 영향이 있나요?

YUNA 일정 해석은 미리보기에서 저장 0이 확인되었습니다. 목표 삭제는 미리보기 후 취소까지만 확인되어 실제 삭제 성공이나 다른 목표 보존까지 검증되었다고 볼 수 없습니다. 기존 저장 키·Cloud schema 변경 여부와 전체 안전 검사의 결과는 기록에서 확인되지 않습니다.

## 대표가 알아둘 점

각 열차의 운영 확인 보고가 있지만 확인한 동작은 서로 다릅니다. 일정 해석 미리보기를 저장 완료로, 삭제 취소를 실제 삭제 완료로 읽지 않도록 구분해야 합니다.

기술 기록은 docs/gemini-reports/_SOURCE-release-log.md의 해당 버전과 PR 기록 참조. 이 문서는 원본 릴리스 표를 쉽게 풀어 쓴 검토용 문서이며, 이번 작성에서 운영 기능을 다시 실행하지 않았습니다.
