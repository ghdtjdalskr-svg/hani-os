## 왜 바꿨나요?

- **휴대폰 화면 회전 잠금이 풀리지 않도록 하기 위해**: 웹앱 매니페스트(`manifest.webmanifest`)에 세로 고정 옵션이 들어 있어, 휴대폰에서 회전 잠금을 켜거나 가로로 돌려 쓸 때 기기 설정과 어긋나는 불편을 바로잡았습니다.
- **10월 20일 Supabase 사용량 초과로 인한 Cloud 일시 중단을 근본적으로 해결하기 위해**: 원인을 점검한 결과, 다른 창을 보다가 돌아올 때마다(`focus`/`visible`/`pageshow`) 예전 보조 스크립트가 전체 생활 기록을 통째로 다시 내려받고, 뉴스룸도 한 번에 500건의 기사 본문과 댓글 전체를 불러오던 것이 전송량 급증의 원인이었습니다.
- **Cloud가 멈춰도 회장님이 내 기록을 언제든 열람·기록하실 수 있게 하기 위해**: 서버 한도 초과나 네트워크 장애로 Cloud 응답이 멈췄을 때 경고창이 반복해서 뜨지 않게 막고, 이 기기에 이미 검증된 기록이 있다면 로그인 화면에서 멈추지 않고 바로 열어 볼 수 있는 안전한 비상 출입구가 필요했습니다.
- **밤과 주말의 사무실 풍경을 더 생생하게 만들고 반가운 첫 인사를 건네기 위해**: 야간·주말에 남아 있는 직원들이 제자리에서 가만히 있지 않고 야식·커피·산책 같은 시간대별 행동을 하게 하고, 하루 처음 앱을 열었을 때 직원들이 단체 치비툰 일러스트로 인사드리도록 기획했습니다.
- **독서·시청 표지 사진도 내 컴퓨터 폴더에 안전하게 보관하기 위해**: 생활 기록 JSON뿐만 아니라 책 표지와 영화·드라마 포스터 이미지도 Google Drive 연결 폴더에 중복 없이 백업할 수 있도록 확장했습니다.

## 데이터나 안전에 영향이 있나요?

- **기기 기록(`hani_os_life_v23`) 최우선 보존**: Cloud 한도 초과나 서버 장애가 발생하더라도 이 기기에 저장된 정상 로컬 데이터를 삭제하거나 오래된 Cloud 데이터로 되돌리지 않습니다. 오프라인으로 열었다가 나중에 다시 로그인할 때도 첫 동기화 직전에 `before_offline_relogin_sync` 복구 스냅샷을 먼저 남깁니다.
- **본인 확인이 끝난 기기만 오프라인 열기 허용**: 보안과 개인정보 보호를 위해, 과거 정상 로그인으로 소유권 증거(`hani_os_cloud_meta_v1`의 `offlineOwner`)가 확인된 기기에서만 Cloud 장애 시 `이 기기 기록으로 열기`가 활성화됩니다. 인증 근거가 없는 기기에서는 열리지 않습니다.
- **저장 공간 여유 보호**: 치비툰 시작 인사는 별도 설정 키(`hani_theme_settings_v1`)만 사용하며, 만약 브라우저 저장 공간이 가득 차더라도 오류를 내지 않고 임시 메모리로 자동 전환해 본앱 진입을 방해하지 않습니다.
