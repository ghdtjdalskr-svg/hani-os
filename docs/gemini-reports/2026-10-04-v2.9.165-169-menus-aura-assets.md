## 왜 바꿨나요?
기능이 늘어나면서 상위 메뉴가 지나치게 복잡해지는 문제를 해결하기 위해 AURA를 성민 오피스 하위로 옮기고 배포센터를 시스템 메뉴로 묶었습니다. 또한 포트폴리오의 밝은 카드 테마에서 전역 테마 글자색이 번져 텍스트가 잘 보이지 않던 명암 대비 문제를 해결했습니다.

아울러 자산 입력 시 평균 매입가를 모를 때 손익이 왜곡되거나 다른 계좌와 섞이는 문제를 방지하기 위해 계좌별 식별과 선택적 매입가 입력 기준을 정립했습니다. 마지막으로 AI 팀의 활동과 개발 기록을 편하게 열람할 수 있도록 Gemini 개발 보고서 메뉴를 별도로 신설했습니다. 이 외에 개별 세부 기획 배경은 Release 기록에서 확인되지 않습니다.

## 데이터나 안전에 영향이 있나요?
기존 원본 저장 키(`hani_os_life_v23`)의 구조 변경이나 Cloud schema 변경, Supabase 쓰기 로직 변경은 없었습니다. 자산 입력 기준 정리는 부분 업데이트(Partial Update) 시 이번 입력에 없는 종목을 임의 청산하지 않고 기존 보유 정보를 유지하도록 보호하며, 원가가 확인되지 않았을 때는 손익·수익률을 거짓으로 계산하지 않도록 안전성을 강화했습니다.

v2.9.166과 v2.9.168은 실제 운영 환경에서 확인 보고되었으나, v2.9.165, v2.9.167, v2.9.169는 GitHub Pages 소스 반영까지만 확인되었고 실제 운영 브라우저 클릭 검증은 미실시 상태입니다.

## 대표가 알아둘 점
메뉴 구조가 단정해지고 포트폴리오의 글자 가독성이 향상되었으며, 자산 입력 시 평균 매입가를 모를 때도 안전하게 입력할 수 있는 기반이 마련되었습니다. 다만 일부 화면 전용 패치(v2.9.165, 167, 169)는 코드 반영만 확인되고 운영 브라우저 확인이 아직 이루어지지 않았으므로 운영 화면에서 가볍게 확인해 주시면 좋습니다.
