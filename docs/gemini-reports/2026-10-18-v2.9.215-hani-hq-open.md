# HANI OS v2.9.215 개발노트 — 새 하니 본사 오픈·Pure White 테마·AI팀 현황 (Release Train #25)

## 이번 업데이트 한줄 요약

5층 루프탑 가든과 4F MIR Station을 갖춘 **새 하니 본사(1F~5F)**를 정식 오픈하고, 좌석 착석 정렬과 벽면 인테리어 문패를 완성했으며, **Pure White 기본 라이트 테마**, **하니일보 이미지 머리말 배너**, **AI팀 7명 업무 현황 데이터화**, **신입 다온·윤슬 입사 예정 프로필**, **지은 실장 주간 소비 첨삭**을 반영한 배포입니다.

## 왜 바꿨나요?

- **건물 전체를 아우르는 '하니 본사' 체계를 완성하기 위해**: 기존에는 메뉴 이름이 '대표실'로만 되어 있어 1층부터 5층까지 건물 전체를 보여준다는 느낌을 주기 어려웠습니다. 하니 전무가 확정한 5개 층 공간 설계(`spatial-216-v1`, 326개 보행 앵커)에 맞춰 메뉴 이름을 **🏢 하니 본사**로 격상하고(4층 탭은 `4F 대표실` 유지), `5F 루프탑 가든`과 4층 `MIR Station`을 새롭게 열었습니다.
- **배경 이미지의 어색한 글자를 지우고 의자 자리에 정확히 앉히기 위해**: 배경 원화에 AI가 임의로 그려 넣은 깨진 글자들을 깔끔하게 제거하고 실제 벽과 유리 칸막이 위치에 맞춘 인테리어 문패(`art-map-v1.json`)를 부착했습니다. 또한 캐릭터가 책상 상판 위에 올라간 것처럼 보이던 문제를 해결하기 위해 전 직원의 좌석 좌표(`seatBounds`)를 실제 의자 위치로 정밀 보정했습니다.
- **가장 깔끔한 순백색 기본 테마를 제공하기 위해**: 밝은 환경에서 종이처럼 깨끗하고 글자가 또렷하게 읽히는 **Pure White** 마감을 기본 라이트 테마로 추가해 6가지 Signature Finish 체계를 완성했습니다.
- **AI팀 업무 현황과 신입 사원 온보딩을 체계화하기 위해**: AI팀 7명의 현재 작업·최근 완료·다음 할 일을 코드 수정 없이도 관리할 수 있도록 전용 데이터 파일(`data/ai-team-status.json`)로 분리하고, 새로 합류할 **다온**(재무자산관리실 리스크 애널리스트)과 **윤슬**(라이프&엔터테인먼트 러닝 리서처)을 `입사 예정` 상태로 먼저 소개했습니다.

## 데이터나 안전에 영향이 있나요?

- 핵심 로컬 저장소 키(`hani_os_life_v23`)와 내부 기준선 버전(`2.9.15-safe-baseline-bootstrap`), Cloud/Supabase 스키마는 변경하지 않았습니다.
- **기존 1F~4F 원화 보존**: 기존 `assets/building/floor-1f~4f-v1.webp` 원본 파일은 삭제하거나 덮어쓰지 않고 그대로 보존했으며, 글자 제거본은 별도 파일(`*-215.webp`)로 추가해 안전하게 전환했습니다.
- **입사 예정 인원 런타임 격리**: 다온과 윤슬은 `activeInRuntime: false`로 설정되어, 정식 입사 전까지는 오피스 좌석 배정이나 라운지 자동 댓글, 결재 라인에 섞이지 않도록 분리했습니다.
