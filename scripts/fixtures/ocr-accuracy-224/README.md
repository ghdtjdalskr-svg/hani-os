# OCR224 synthetic fixtures

These are the original synthetic corpus, baseline mapper and protected-path
manifest from the OCR224 worktree (`hani/kiwoom-code-fix`, baseline `06519be`).
They were previously read from an untracked `artifacts/ocr-accuracy-224` directory,
so a fresh worktree could not execute the test. They contain synthetic labelled
JSON, not account screenshots or user records. The corpus pins the original
mapper SHA-256; protected function/write-call/Edge hashes remain unchanged.

Input fixtures belong here and are never regenerated by the test. Only measured
output is written to `artifacts/ocr-accuracy-224`. Whole main/index preservation
uses the Git release225 oracle plus explicitly listed later release changes;
the original main/index hashes are still verified against Git `06519be`.
